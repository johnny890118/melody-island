# Melody Island
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Friends listening together in private rooms of 2–20 people, confirmed by the owner.

## Product Purpose
Create an island, invite friends, find YouTube music and listen to a shared queue.

## Capabilities and Constraints
Next.js, React, Firebase and React Three Fiber. Preserve the interactive 3D island as the homepage's main element. Provide unit and E2E tests; improve security, concurrency, performance and synchronization. Never test against production data.

## Brand Commitments
Melody Island. Traditional Chinese interface. The owner requests Awwwards-level craft, not a promise of winning an award. Existing island GLB must remain central.

## Evidence on Hand
Existing island, bird and plane GLBs in public/models. No awards, customer counts or testimonials supplied.

## Open Decisions
Production credentials, existing deployed Firebase rules and legacy-room migration require environment-specific verification.

## Implementation Commitments
The owner requests TypeScript/TSX throughout application code, tests and scripts. Shared UI uses shadcn/ui, Lucide is the only interface icon library, and Impeccable determines the visual design. Verified milestones are committed and pushed to the task branch.
